## Project Description
A collection of programs, Jupyter notebooks, and reports developed for the "Computational Methods in Science and Technology" (Numerical Methods) university course.

## Laboratories
| Laboratory | Description | Source |
|------------|-------------|--------|
| **Lab 1** | Analysis of error accumulation in recursive sequences. | [labs/lab1](labs/lab1/) |
| **Lab 2a** | Polynomial interpolation using Lagrange and Newton methods. | [labs/lab2a](labs/lab2a/) |
| **Lab 2b** | Hermite polynomial interpolation. | [labs/lab2b](labs/lab2b/) |
| **Lab 3** | Spline interpolation. | [labs/lab3](labs/lab3/) |
| **Lab 4a** | Algebraic least squares polynomial approximation. | [labs/lab4a](labs/lab4a/) |
| **Lab 4b** | Trigonometric least squares approximation. | [labs/lab4b](labs/lab4b/) |
| **Lab 5** | Non-linear root-finding using the Secant method and Newton's method. | [labs/lab5](labs/lab5/) |
| **Lab 6** | Gaussian elimination and Thomas algorithm for for linear systems. | [labs/lab6](labs/lab6/) |
| **Lab 7** | Jacobi method for linear systems. | [labs/lab7](labs/lab7/) |
| **Lab 8** | Numerical solutions of Ordinary Differential Equations. | [labs/lab8](labs/lab8/) |

## Prerequisites

- GCC (GNU Compiler Collection) and Make (for C++ programs in Lab 1)
- Python 3 with Jupyter Notebook (required libraries: `numpy`, `matplotlib`, `pandas`)
- A PDF reader (to view the laboratory reports)
